# Dados de exemplo

Esta pasta contém uma amostra pequena dos dados produzidos pelo Michael Opportunity Intelligence.

Os arquivos servem apenas para demonstrar o schema e permitir análises locais sem publicar o dataset operacional completo.

## Arquivos

- `jobs_sample.json` — amostra de vagas já classificadas.
- `jobs_sample.csv` — a mesma amostra em formato tabular.
- `market_sample.csv` — quatro snapshots comparáveis do mercado.
- `skills_sample.csv` — evolução de algumas das skills mais frequentes.

## Importante

Os registros foram derivados de informações públicas de boards de recrutamento e representam somente uma pequena amostra observacional.

O repositório público não deve conter:

- `data/jobs/`
- `data/companies/`
- `data/market/`
- `data/state/`
- `data/sources/`
- `data/exports/`
- `data/parquet/`

O histórico operacional completo permanece no ambiente privado.
